Règles du jeu Snake

1. Utilisez les touches fléchées pour déplacer le serpent.
2. Mangez les pommes rouges pour marquer des points.
3. Chaque pomme augmente la longueur du serpent.
4. Si le serpent heurte un mur ou lui-même, le jeu est terminé.
5. Essayez d'obtenir le meilleur score possible !
